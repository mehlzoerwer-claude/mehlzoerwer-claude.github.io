Clownfischserver

// Telegram-controlled Linux Server Manager

v0.4.14 GPL-3.0 Ubuntu 24.04 Python Ollama Telegram

Ein selbst-gehosteter Telegram-Bot, der deinen Linux-Server per Chat steuert. KI-gestützt via Ollama (lokal first), OpenRouter als Cloud-Fallback. Keine Cloud-Abhängigkeit, keine laufenden Kosten, DSGVO by Design.

💬

/shell · /run

Shell-Befehle mit KI-Bestätigung — gefährliche Commands brauchen ein /ja

🧠

Local AI First

Ollama lokal, OpenRouter als Fallback — kein Abo, keine Daten in der Cloud

📸

Snapshots & Rollback

Automatische Backups vor gefährlichen Befehlen, Rollback per Telegram

🔄

Self-Update

ZIP an den Bot schicken → fertig. Kein SSH für Updates nötig

💻

/code via Aider

Direkt Code generieren und auf dem Server ausführen

🛡️

DSGVO by Design

Secrets nie über Telegram, .env geschützt, Audit-Log geplant

# Schnellinstallation
wget https://github.com/mehlzoerwer-claude/clownfischserver/archive/refs/heads/main.zip
unzip main.zip && cd clownfischserver-main
bash install.sh
